# Project Final Review and Reflection

## Addressing Relevant Implications

### NAME OF IMPLICATION: Usability

I implicated the heuristic of usability into my website by having the main functions of the website such as checking what tasks are on the list or just creating a new task being simplistic and efficient to use, and not wasting any time by only needing the fewest clicks to function the website. It also implicated usability by having a error prevention in the create new task form, the system prevents the user from creating a task if any of the boxes hasnt been filled out aswell as using a dropdown menu in the topic and urgency to prevent the user from inputing invalid data.


### NAME OF IMPLICATION: Accesibility

I implicated the heuristic of accesibiity into my website by first, having a color pallete that contrasts well between each other. These colors will help users who struggle with their eyesight to access and easily function the website. Secondly, the website will be able to appealingly layout based on what size of device the user is operating the website on, this will help the users who may not have a phone or computer accesible to still be able to use the website well.


### NAME OF IMPLICATION: Functionality

I implicated the heuristic of functionality into my website by developing each non-interactable and interactable thing to function as it should. The add button adds a task, the delete button deletes the tasks all the back buttons bring the user back to the list page and the plus sign beside the task brings the user to the details page of that specific task. Overall this website is completely functional and operates as it should


### NAME OF IMPLICATION: Aesthetical

I implicated the heuristic of aesthetical into my website by using a color pallete of turquoise and pink that works and contrasts well with eachother that was decided by my end user. The entire website has fitting fonts according to wheres its placed, colors being different shades based on where its placed and layout of the list to look formal. to give the end user an experience of a visually appealing functional website. Overall this website uses colors fonts and layout to make it aesthtically pleasing.


### NAME OF IMPLICATION: End user

I implicated the heuristic of end user into my website by building the features and design based upon what my end user specificly liked and disliked. The color variation, details page, remove button and overall layout of my website was driven by the feedback from my end user. Overall the entire desing and developement of my website it based on what the end users thoughts are about different desings and functions.


## Overall Review

This final system review went well because my website met all the implications of usability, functionality, end user, aesthetical and accesibility I intended it to.
